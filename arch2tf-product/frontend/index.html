Push to GitHub

      

        Pushes into an existing repo you specify — commits the generated Terraform
        (under terraform/<environment>/) and the source diagram itself
        (under diagrams/<environment>/) on a new branch, then opens a
        Pull Request against that repo's default branch. Environment comes from what you picked on the upload
        screen, so dev/staging/prod never collide. Only those paths are touched — everything
        else already in the repo is left alone. Your token is sent for this request only — it is never saved.
